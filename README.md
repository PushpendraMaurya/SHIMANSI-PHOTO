Fashion & Textile Designer — Minimal Portfolio

What I built
- A single-page HTML/CSS/JS portfolio using your provided images.
- Uses an editorial, minimal layout and a simple lightbox.

Where to edit content
- Open `index.html` to replace the designer name, hero statement and contact details with the exact text from your PDF.
- Update `data.js` to refine `projects`, `experience` and `process` arrays with accurate text taken from the PDF.

How to view
1. In Finder, open this folder and double-click `index.html` to view in a browser.
2. For best results host it via a simple static server (optional):

```bash
python3 -m http.server 5173
# then open http://localhost:5173
```
